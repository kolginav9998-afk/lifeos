# Ключ подписи debug-APK

`debug.keystore` — **учебный открытый ключ**, лежит в репозитории намеренно: без него каждая сборка в GitHub
подписывалась бы новым случайным ключом, и Android не давал бы ставить новую версию поверх старой.

- Пароли: `android` / алиас `androiddebugkey` (стандартные для debug-сборок).
- Подходит для личного использования. Не используй для публикации в магазинах.
- Минус: любой, у кого есть этот файл, может подписать свой APK тем же ключом. Поэтому **ставь APK только из
  своего репозитория** (Releases → `latest-apk`). Для широкой раздачи нужен закрытый ключ, хранимый в секретах GitHub.
