# Движок обучения «с абсолютного нуля» (контракт)

Документ для тех, кто пишет содержание курсов и экран «С нуля». Правила проверяются тестами (`tests/zero-kit.test.mjs`), нарушение правил = красный тест.

## 1. Зачем и главный принцип
Владелец начинает английский и иврит **с нуля**: не знает ни алфавита, ни звуков, ни направления письма, ни огласовок. Поэтому:
- маршруты идут **ступенями**: урок открывается, только когда освоены его предпосылки (`needs`);
- на практике показываем **только то, что уже выучено**: слово можно показать, если все его буквы, сочетания и знаки уже введены;
- «просмотрено», «освоено» и «подтверждено» — **три разных статуса** с разными доказательствами.

Это поверх существующего: уроки, карточки (`srs.js`), навыки (`skills.js`), озвучка (`speech.js`), практика говорения (`speaking.js`), поиск (`search.js`) работают как раньше. Старые курсы `english` («Английский: быстро») и `hebrew` («Иврит: разговор и фразы») остаются как **следующая ступень** (`after`); на них показываем мягкую подсказку, но не блокируем.

## 2. Маршруты
| id | название | язык (`lang`) | ветка (`branch`) | префикс уроков | файл |
|---|---|---|---|---|---|
| `enzero` | Английский с нуля | english | — | `ez-NN` | `c-zero-en.js` (+ части `zero-en-*.js`) |
| `hezero` | Иврит: письмо и чтение с нуля | hebrew | modern | `hz-NN` | `c-zero-he.js` (+ `zero-he-*.js`) |
| `hebib` | Библейский иврит (отдельный граф, открывается после огласовок `hezero`) | hebrew | biblical | `hb-NN` | `c-zero-hb.js` (+ `zero-hb-*.js`) |

Курс `diction` («Дикция») — обычный курс (`zero` не нужен), его описывает команда дикции.
Каждый файл маршрута — `export default {…}` — и подключён в `academy.js` (`TRACKS`, в конце списка). Файл одного модуля не больше 64 КБ: если больше, выноси данные в части `zero-xx-*.js` (чистые данные, без интерфейса).

## 3. Схема курса и урока
Курс — как обычный курс `academy.js` (`mentor`, `intro`, `plan`, `sources`, `lessons`; `validateTrack` проверяет всё это) плюс поля маршрута:
```js
{ id: 'enzero', zero: true, lang: 'english' | 'hebrew', branch: 'modern' | 'biblical' /* только иврит */,
  after: 'english',                       // курс, к которому идти дальше
  resources: ['british-council', …],      // id из каталога внешних ресурсов (раздел 8)
  lessons: [ урок, … ] }                  // порядок в списке = рекомендуемый; needs ссылаются только на уроки выше
```
Урок (к обычным полям `id, title, minutes, body[], task, cards[[q,a]]` добавляется):
| поле | смысл |
|---|---|
| `goal` | «после урока я смогу…»: одна фраза 15–120 знаков без точки в конце (как в `c-goals.js`) |
| `stage` | название этапа для карты маршрута («Звуки», «Алфавит», «Фоника»…) |
| `needs` | массив id уроков-предпосылок (можно из другого курса); пусто у входа в маршрут |
| `intro` | что вводит урок. Английский: буквы и сочетания через пробел (`'a b c'`, `'sh ch'`, `'a_e'` = a + любая согласная + e). Иврит: буквы и огласовки (`'א ב ג'`, `'ַ ָ'`) |
| `sight` | слова целиком, которые можно показывать без разбора (`['the','said']`); действуют и в следующих уроках цепочки |
| `showcase` | слова, которые этот урок намеренно показывает «на слух» (например, пример звука); действуют только в этом уроке |
| `milestone` | метка этапа: `'niqqud'` ставится на урок, после которого огласовки освоены |
| `plain` | `true` — в уроке есть слова без огласовок; допустимо только после `milestone: 'niqqud'` в цепочке |
| `table` | таблица-шпаргалка: массив строк-массивов ячеек |
| `words` | слова, которые урок даёт для чтения (проверяются на допуск так же, как задания) |
| `drills` | **не меньше 8** заданий (раздел 4), из них проверяемых не меньше `check.n + 2` |
| `check` | `{ n: 6, pass: 0.8 }` — размер и порог проверки (значения по умолчанию) |
| `decay` | множитель забывания 0.5–3 (больше = забывается быстрее, повторять чаще); по умолчанию 1 |

## 4. Задания (`zero-kit.js`, все конструкторы — чистые функции)
`choose(q, right, wrong[], o)` · `listen(say, right, wrong[], o)` · `typed(q, ok[], o)` · `order(q, tiles[], {dir})` · `match(q, pairs[][], o)` · `read(text, o)`.
Общие поля `o`: `big` (крупный знак над вопросом), `say` (что озвучивает кнопка «Послушать»), `lang`, `hint` (подсказка; если ею воспользовались, ответ не засчитывается), `explain` (пояснение после ответа). У `order` плитки перечислены **в порядке чтения**; `dir: 'rtl'` для иврита (интерфейс показывает собранное справа налево). `read` — самооценка (прочитал вслух: получилось / нет), она **не входит** в проверку и не доказывает освоение. Ключ `type:` в заданиях не использовать (его ищет тест реестра): вид лежит в `t`. Разбор ответа и выбор заданий для проверки — `gradeDrill`, `pickCheckItems` (одно зерно → один и тот же набор).

## 5. Статусы навыка (один урок = один навык)
Считаются из журнала записей, ничего отдельно не хранится:
| статус | значение | как получают |
|---|---|---|
| `locked` | закрыто | какая-то из `needs` не в статусах mastered / confirmed / review |
| `new` | открыто, не начато | предпосылки готовы, записи `lesson` нет |
| `seen` «Просмотрено» | прочитано, но не доказано | есть запись `lesson` (кнопка «Урок пройден») |
| `mastered` «Освоено» | доказано проверкой | последняя проверка (`quiz` или `placement`) набрала `ok/n ≥ pass`, заданий в ней `n ≥ 5` |
| `confirmed` «Подтверждено» | устояло при неожиданной проверке | освоено, и позже прошла проверка `surprise` (не раньше чем через сутки после освоения) |
| `review` «Пора повторить» | было освоено, срок вышел | `now > dueAt` |
Правила:
- **Подсказка = ответ не засчитан.** Последняя проверка решает: провал `surprise` возвращает навык в `seen`, провал обычной `quiz` тоже (честное измерение важнее приятного статуса).
- `dueAt = дата последней успешной проверки + 3 дня × 2,2^(успешных подряд − 1) ÷ decay` (3, 7, 16, 35, 77 дней). Навык в `review` остаётся допуском для следующих уроков.
- **Допуск (gating):** содержание урока (текст, задания, карточки) показывается только при статусе, отличном от `locked`. Закрытый урок показывает, чего не хватает, и кнопку «Я уже умею это: проверить» — проверка `placement` по первой недостающей предпосылке (после успеха предпосылка получает статус `mastered` с доказательством «входная проверка»). Нарушение допуска = ошибка.
- **Неожиданные проверки (`surprise`):** не чаще одной в сутки, 3–4 вопроса из уже освоенного навыка (приоритет `review`), без указания заранее, какой навык и что это зачётная проверка; в конце результат и честное «подтверждено / надо повторить». В Справке это объяснено.
- Карточки уроков (`cards`) попадают в повторение (`srs`) только у пройденных уроков, как и раньше.

## 6. Записи (события): только добавляются
- `zcheck` — попытка проверки. `payload: { track, lesson, kind: 'quiz' | 'surprise' | 'placement', n, ok, hints, date }`; запись-обёртка: `source` = kind, `confidence` = доля верных ответов без подсказок (0–1), `evidence: [{ kind: 'test_result', ref: '<lesson>:<ok>/<n>' }]`; `id` = `zc:<урок>:<ts в 36-ричной системе>`.
- `resource` — отметка о внешнем курсе. `id: 'res:<resourceId>'` (одна запись на курс, обновляется), `payload: { id, status: 'not_started' | 'in_progress' | 'completed' | 'abandoned', note, date }`.
- Просмотр урока — существующая запись `lesson` (`makeLessonDone`).
- Новые типы добавить в `REGISTRY` (`registry.js`), поля в документацию (`node -e …` из TEAM-BRIEF), `zcheck` — `privacy: 'learning'`, `analytics: true`; `resource` — `privacy: 'learning'`, `analytics: false`.

## 7. Область допуска: что проверяет тест
Для каждого урока считается область: все `intro`, `sight` и `milestone` из цепочки `needs` плюс сам урок. Проверяются **задания, карточки, таблица и `words`** (текст урока `body` — нет).
- **Английский:** каждое латинское слово обязано (а) состоять из введённых букв и (б) не содержать сочетание, которое маршрут вводит позже (`sh`, `th`, `ee`…), либо быть в `sight`/`showcase`. Транскрипция внутри `/…/` и `[…]` не считается чтением. Первые слова строятся только из освоенных букв и сочетаний; пример звука «на слух» оформляй как `showcase`.
- **Иврит:** каждая буква и каждый знак должны быть введены (`intro`); конечные формы ך ם ן ף ץ вводятся отдельным уроком после всех обычных букв; слово из двух и более букв **без огласовок** запрещено, пока не пройден этап `milestone: 'niqqud'`, а после него — только в уроках `plain: true`.
- Русский текст в заданиях не проверяется; если в нём есть латиница или иврит, она проверяется как чтение. Задание с `lang: 'russian'` пропускается.

## 8. Каталог внешних ресурсов (`zero-resources.js`)
Только ссылки и описание **своими словами**; чужое содержание не копируем. Поля: `id, title, subject, level, lang` (язык материалов), `cost: 'free' | 'freemium' | 'paid' | 'mixed'`, `costNote` (что бесплатно, что платно), `url` (официальный), `format: 'course' | 'mooc' | 'video' | 'interactive' | 'book' | 'flashcards'`, `availability: 'ok' | 'unknown' | 'down'`, `lastChecked` (дата `ГГГГ-ММ-ДД` **только** если адрес реально открылся при сборке, иначе `null`), `note` (наше описание в одну-две фразы), `provider`. Статус прохождения не в каталоге, а в записях `resource`. Идентификаторы (ровно эти двадцать): `british-council, usa-learns, bbc-learning-english, duolingo, hebrewpod101, hebrewglot, ochjs, yale-psychology, cs50p, helsinki-python, stepik, kaggle-learn, freecodecamp, coursera, cisco-netacad, sqlbolt, linux-journey, microsoft-learn, openlearn, anki`.

## 9. Экран «С нуля» (`view-zero.js`, дочерние `view-zero-lesson.js`, `view-zero-check.js`, `view-zero-catalog.js`)
- Карта маршрута: выбор курса (английский / иврит / библейский иврит), этапы с уроками, у каждого статус (слово + значок, не только цвет), кольцо прогресса маршрута, блок «Пора повторить: N», кнопка «Быстрая проверка» (неожиданная, раздел 5), кнопка каталога внешних курсов.
- Плеер урока: текст и таблица (иврит с `dir="rtl"`, `lang="he"`), кнопки «Послушать» (`speech.js`; если голоса нет, сказать об этом один раз), задания по очереди с мгновенным разбором и `explain`, подсказка, затем проверка и итог со статусом. Всё доступно с клавиатуры и экранного диктора.
- Закрытый урок: список недостающих предпосылок и «Я уже умею это: проверить».
- В «Учёбе» (`view-learn.js`) курсы `zero: true` не показываются списком уроков (иначе обойдётся допуск): вместо них карточка «Курсы с нуля» со ссылкой на экран «С нуля». Поиск по урокам (`searchAcademy`) не выдаёт содержимое закрытых уроков.
- Навыки: когда урок получает `mastered`/`confirmed`, в «Навыках» предлагается навык с доказательством «проверка 6/6, ГГГГ-ММ-ДД».

## 10. Иврит: особенности
RTL везде (`dir="rtl"`, `lang="he"` на ивритских фрагментах, плитки собираются справа налево); кириллическая транслитерация — только подсказка и постепенно исчезает; пять конечных форм — отдельный навык; огласовки сначала по одной, потом в слогах; похожие буквы (ב/כ, ד/ר, ה/ח/ת, ו/ז/ן, ג/נ, ע/צ) разбираем парами; **современный и библейский иврит — разные ветки с разными графами и текстами**. Тексты Библии (Масоретский текст) в общественном достоянии, пояснения и переводы пишем сами; божественное имя не огласовываем.

## 11. Честные границы
- Содержание курсов написано ИИ и **не проверено носителем или преподавателем**. Это нужно честно сказать в первом уроке каждого курса и в Справке; рекомендовать показать курс преподавателю.
- Озвучка использует голоса телефона. Их может не быть (особенно иврит): тогда интерфейс говорит об этом, а урок остаётся пройденным по тексту и транслитерации.
- Приложение не распознаёт речь и не слушает микрофон: говорение — самооценка и таймер (`speaking.js`).
- «Освоено» означает, что человек прошёл проверку, а не что он владеет языком; приложение не выставляет уровней CEFR.

## 13. Памятка автору содержания
1. Запусти `node --test tests/zero-kit.test.mjs tests/academy.test.mjs tests/r310.test.mjs` после каждого файла.
2. Одна новая буква или знак за раз; группы по 3–5 знаков; сразу тренируй различие похожих.
3. Вводи сначала звук (на слух), потом знак. В каждом уроке — слушать, повторить вслух, прочитать, выбрать, собрать.
4. Не меньше 8 заданий, из них не меньше 8 проверяемых; виды чередуй; неверные варианты — реальные частые ошибки, а не случайные слова.
5. Не показывай слово, пока не введены все его знаки. Если слово нужно как пример звука, это `showcase`.
6. Весь русский текст простыми словами, короткими предложениями, без жаргона. Никаких обещаний вроде «выучишь за N дней».
