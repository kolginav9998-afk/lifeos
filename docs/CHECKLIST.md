# Что проверить на телефоне

После каждого обновления пройди нужный раздел и ответь одним словом: **«прошёл»** или **«не прошёл» + что именно не так** (можно скриншотом). Если что-то не получилось — это нормально, значит, мы нашли ошибку.

## 0. Обновление (каждый раз)
1. Сайт: открой https://kolginav9998-afk.github.io/lifeos/ → внизу экрана или в «Ещё → О приложении» должна быть **последняя версия** (сейчас R3.6).
2. Приложение: скачай свежий APK по ссылке из `docs/GUIDE.md` и установи поверх (данные должны остаться). Если телефон ругается на подпись, один раз удали старую версию, предварительно сделав **резервную копию** (Ещё → Резервные копии).
3. Все прежние задачи, привычки, расходы и заметки на месте.

## 1. Дневник и здоровье
1. Дневник → «Утро»: поставь время «лёг/встал» — сон считается сам. Оцени самочувствие. Сохрани. Заголовок получает «✓».
2. «Вечер»: настроение, кофе, тренировка (степпер «+» начинается с разумного значения). Сохрани.
3. «Дневник»: сверху **Вопрос дня**. Нажми «Ответить», напиши пару строк с `#тегом`, сохрани. Теги видны под текстом.
4. Здоровье: добавь вес и давление. Появляются график, 7-дневное изменение, ориентир ИМТ после ввода роста.
5. Здоровье → «Дыхание 4–6» → «Начать»: круг увеличивается на вдохе и уменьшается на выдохе. Закончи и оцени стресс.

## 2. Учёба
1. Развитие → Учёба: видно 8 курсов и «Свои карточки».
2. Открой любой курс → урок → «Отметить пройденным» (урок остаётся раскрытым, отметка ✓).
3. «Начать повторение»: «Показать ответ» → «Забыл / Трудно / Помню». Забытые карточки возвращаются в этой же сессии.
4. «Наставник» → «Копировать» → вставь в любой чат с ИИ: запрос вставился целиком.
5. «Проверить мой ответ с ИИ» в уроке тоже копирует запрос.
6. «Сегодня»: появилась карточка «Слово дня» (английский и иврит), по касанию слова виден перевод.

## 3. Проверки (тесты)
1. Развитие → Тесты → «Быстрая проверка» (около 5 минут). Положи телефон на стол или держи двумя руками, в тишине.
2. Пройди все тесты: реакция (нажимать на зелёный), «жми / не жми», цвет слова, цифры, счёт, слова. Можно нажать «Прервать» — пройденное сохранится.
3. В конце список результатов; после 5–6 прохождений в разные дни добавится сравнение с твоей нормой.
4. Развитие → Аналитика: отклонения, подсказки, график по тестам. Проверь, что «Скачать ZIP для аналитики» сохраняет файл, а «Скопировать сводку для ИИ» копирует текст.

## 4. Эксперименты
1. Аналитика → «Новый эксперимент» → выбери готовый (например, «Кофе только до 14:00») → «Начать».
2. На «Сегодня» появился значок «Эксперимент: фаза A/B». Через две недели в карточке будет итог.
3. Важно: данные для сравнения берутся из ежедневных отметок — чем регулярнее, тем точнее.

## 4а. Новое в R3.4
1. «Сегодня» → в строке добавления напиши `потратил 350 на кофе` → появляется кнопка «Добавить расход…». Нажми — расход появился в «Деньги». Так же проверь `вес 72,4` и `заметка: проверить`.
2. Дневник → Тренировки → «Начать» (шаблон «Дом: всё тело A») → введи повторения и нажми «Подход ✓» → идёт таймер отдыха. Закрой и открой приложение — тренировка на месте. «Завершить» сохраняет.
3. «Сегодня» → «Фокус» → 25 минут → после запуска виден таймер; «Остановить» до 5 минут ничего не пишет.
4. Деньги → Планы: задай лимит для «Еда», создай копилку «Отпуск», добавь подписку и нажми «Записать платёж».
5. Здоровье: появилась панель сна (после трёх утренних отметок) и список лекарств.
6. Развитие → Аналитика → Отчёты: «Скопировать» итоги месяца и сводку для врача — вставь в заметку и посмотри.
7. Заметки: выбери шаблон, поставь `#тег` и `[[ссылку]]` на другую заметку — теги и ссылки кликабельны.
8. «Сегодня» → «Тяжёлый день» оставляет три дела; Ещё → «Размер текста» → «крупный» увеличивает шрифт везде.
9. Поиск (лупа) по слову из курса (например, `шэдоуинг`) открывает нужный урок.

## 4б. Новое в R3.5
1. «Сегодня» → «Люди» → «Новый человек»: имя, день рождения (например, `15.03`), «раз в 2 недели». Сохрани. Если день рождения в ближайшие 2 недели, на «Сегодня» появится чип «🎂».
2. Развитие → «Цели» → «Новая цель»: название, 1–2 измеримых результата (число и единица). Введи «Сейчас» и нажми «Обновить» — полоска движется. «Достигнута» переносит цель в закрытые.
3. «Привычки» → «Новая привычка»: заполни «Кем я становлюсь». Под названием появится строка «Я — …». Если привычке больше двух недель, внизу вверху появится «Пересмотр привычек» с советом по каждой.
4. Дневник → «Здоровье» → «Мысли и эмоции» → «Записать мысль»: заполни и сохрани. Запись появится в списке, а в «Журнале дня» на «Сегодня» — строка «Мысль».
5. Дневник → «Вечер»: поставь галочки «Овощи или фрукты», «Белок», «Сладкое» и нажми «Сохранить вечер». Закрой и открой приложение — галочки на месте.
6. Учёба → «Английский» → повторение: среди карточек встречаются предложения с пропуском («I ___ to the shop yesterday. (go)»).
7. Дневник → «Заметки» → шаблон «Передача смены (склад)».

3. Дневник → «Здоровье» → «Включить режим болезни». На «Сегодня» появилась плашка, «Проверка дня» исчезла, привычки показывают «пауза». «Я поправился» всё возвращает.

7. Ещё → Внешний вид → «Простой режим»: внизу остаются три вкладки. Выключи его обратно. В «О приложении» должна быть строка «Запуск: …».
8. Ещё → «Резервные копии и экспорт» → «Всё читаемо (Markdown)»: в файле появились разделы «Люди», «Рефлексия» и др., если в них есть данные.

## 5. Напоминания (только приложение)
1. Ещё → Напоминания → включи. Выбери время вечерней отметки.
2. «Тестовое уведомление через 5 секунд» — свернуть приложение и дождаться. На Huawei разреши автозапуск и работу в фоне.

## 6. Аккаунт и синхронизация (после развёртывания сервера, см. `docs/SERVER.md`)
1. Ещё → Аккаунт → создать аккаунт (пароль + **код восстановления** — сохрани его отдельно от телефона).
2. Добавь задачу в приложении → открой сайт на другом устройстве, войди тем же именем и паролем → задача появилась.
3. Выключи интернет, добавь запись, включи интернет → запись синхронизировалась.

Если что-то из этого не прошло, напиши номер пункта и что увидел. Остальное я исправлю.
