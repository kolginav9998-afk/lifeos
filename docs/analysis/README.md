# Разбор выгрузки на компьютере

Это необязательная часть. Приложение само показывает связи и выводы в «Развитие → Аналитика». Скрипт и ноутбук нужны, если хочется посмотреть данные глубже, на компьютере.

## Что понадобится

1. Файл ZIP: в приложении «Развитие → Аналитика → Выгрузка для анализа». В нём только таблицы проверок, отметок, привычек, замеров и занятий. Текстов дневника и заметок, сумм денег, паролей и ключей там нет.
2. Python 3.9 или новее (бесплатно, [python.org](https://www.python.org/downloads/)). Для скрипта больше ничего ставить не нужно.

## Быстрый вариант: скрипт

```bash
python3 analyze.py lifeos-analysis.zip
python3 analyze.py lifeos-analysis.zip --out report.md
```

Скрипт показывает:

- тренд результата проверок с доверительным интервалом;
- средний результат по дням недели;
- связи результата со сном, настроением, кофе, движением, экраном, питанием и привычками. Вечерние факторы берутся со сдвигом на день (кофе вечером влияет на утро следующего дня), дни режима болезни исключаются, а поправка на множество сравнений защищает от случайных находок.

Только стандартная библиотека Python. Скрипт ничего не отправляет в сеть и ничего не меняет в файле.

## Подробный вариант: ноутбук

`lifeos-analysis.ipynb` — шаблон для Jupyter с графиками. Нужны пакеты:

```bash
pip install jupyter pandas matplotlib
jupyter notebook lifeos-analysis.ipynb
```

Положи ZIP рядом с ноутбуком и запускай ячейки по порядку.

## Как читать результаты

- ρ (ро) — сила связи от −1 до +1. Около нуля — связи нет.
- p и q — насколько случайной могла быть находка. Если q меньше 0,1, связь стоит проверить; больше — скорее всего шум.
- Связь не доказывает причину. Чтобы проверить, измени одну вещь на 1–2 недели и сравни периоды: в приложении для этого есть эксперименты.
- Чем меньше дней, тем легче увидеть закономерность там, где её нет. До 20–30 дней выводы ненадёжны.
