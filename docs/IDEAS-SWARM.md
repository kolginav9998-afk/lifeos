# Идеи сворма агентов (собрано 2026-11-17)

Пять агентов-идеологов независимо осмотрели код и предложили идеи, которых нет в [IDEAS.md](IDEAS.md) и [COUNCIL.md](COUNCIL.md). Формат: «[категория] идея — зачем». В конце каждого раздела — ТОП-5 по мнению агента; в конце файла — сводный шорт-лист.

## 1. Курсы и проверки знаний

**Форматы уроков и повторений**
- [формат] «Объясни сам»: после урока пересказ темы двумя предложениями; зачёт по наличию опорных слов из списка (правило, без ИИ) — эффект Фейнмана вместо узнавания.
- [формат] Спиральная проверка: в quiz урока подмешивать 1–2 задания из прошлых уроков той же ступени — ретроспективное повторение в потоке, без отдельного экрана.
- [формат] Диктант на слух: связка listen → typed (услышал слово — вписал); только слова из области допуска — орфография и аудирование.
- [формат] Cloze-карточки: «закончи фразу» из карточек уроков (скрыть ключевое слово по правилу) — активное вспоминание без нового контента.
- [формат] «Найди ошибку»: фраза с одной типичной ошибкой, указать её — использует готовые дистракторы, учит замечать ошибки.
- [формат] Итог этапа: после каждого stage обзорный урок без нового материала — видимая точка достижения.
- [формат] Контрастные пары: похожие буквы/звуки вперемешку в одном задании с вариантом «оба неверных» — дискриминация вместо узнавания по одному.
- [формат] Урок-чтение вслух: текст урока + таймер + целевое время по слогам, самооценка — перенос «читаю глазами» в «читаю голосом».
- [формат] Микро-урок на 90 секунд: один факт из пройденного + один вопрос для дней «нет сил» — серия жива, прогресс не накручивается.

**Мотивация без давления**
- [мотивация] Гибкая серия «5 из 7» — серия жива при 5 днях занятий в неделю, не подряд — один пропуск не ломает мотивацию.
- [мотивация] Защита серии болезнью: день с отметкой болезни не разрывает серию.
- [мотивация] «Самый лёгкий следующий шаг» на главном: один конкретный минимум (урок на 2 минуты или 3 просроченные карточки).
- [мотивация] Кнопка «сегодня минимум»: очередь повторений урезается до 5 карточек, ноль новых — профилактика выгорания.
- [мотивация] «На этой неделе ты стал уметь…» — фраза по новым skill в недельном обзоре.
- [мотивация] Выбор темпа «спокойный / обычный» — меняет newPerTrack и напоминания; в интерфейсе нет понятия «отставание».

**Адаптивность под слабые места**
- [адаптивность] Ошибки по видам заданий: в zcheck.payload хранить разбивку ok/n по типам (choose/listen/typed/order/match); слабый вид чаще давать в повторениях — тренировка слабого канала по данным.
- [адаптивность] Автоматический decay: после второго провала повторения поднимать decay урока до 1.5–2 (и наоборот) — интервалы под реальное забывание.
- [адаптивность] Подсказки как сигнал: уроки с долей подсказок >30 % в проверках предлагать к перечитыванию раньше 30 дней.
- [адаптивность] Детокс «пиявок»: карточка с lapses ≥3 получает режим «разобрать» с подсказкой до ответа.
- [адаптивность] Лучшее окно занятий: по ts оценок считать часы с большей долей верных и советовать их для напоминаний.
- [адаптивность] Слабые ударения → свои карточки: слова из miss дикции одной кнопкой в ucard для SRS.

**Межпредметные связки**
- [связки] Дикция + английский: чтение вслух знакомых фраз из английской колоды с замером WPM.
- [связки] Здоровье → эксперимент в один тап: уроки c-health предлагают готовый пресет experiments.js («Кофе до 14:00»).
- [связки] Урок → привычка: на уроках с практическим task кнопка «сделать привычкой».
- [связки] Данные → своя аналитика: в уроках c-data задание «посмотри свою пару сон↔реакция» (bt-analytics уже считает).
- [связки] Разминка перед фонетикой: на уроках про звуки подсказка «1 минута разминки» с записью как warmup дикции.
- [связки] Конспект → карточки: из lessonnote по нажатию создать 2–3 свои карточки (с подтверждением).

**Данные и новые проверки**
- [данные] Тепловая карта слабых мест: матрица «урок × вид задания» из zcheck + lapses.
- [данные] Календарный профиль: «в какие дни недели ты занимаешься», совет ставить напоминания на провальные дни.
- [данные] Сон ↔ усвоение: точность zcheck как outcome в bt-analytics.
- [данные] Отчёт «для преподавателя»: статусы и слабые виды заданий одним текстом — шаг «покажи учителю» в одно нажатие.
- [данные] Surprise не назначать в дни болезни и очень низкой энергии.
- [проверки] Закрытая книга: через неделю после освоения показать task урока без текста — recall вместо recognition.
- [проверки] Проверка переноса: факт, выученный через choose, проверить форматом typed (и наоборот).
- [проверки] Скорость как показатель автоматичности: верный, но медленный ответ в surprise считать «неуверенным».
- [проверки] Смешанная surprise: одна проверка по нескольким урокам разом (по 1–2 вопроса).
- [проверки] Каскадный placement: «Я уже умею это» проверяет цепочку предпосылок до целевого урока.

**ТОП-5:** 1) ошибки по видам заданий в zcheck; 2) спиральная проверка; 3) автоматический decay; 4) диктант на слух; 5) урок → привычка/эксперимент в один тап.

## 2. Дизайн и визуальный опыт

- [темы] Сезонные палитры: перезапись --accent/--grad/--glow по дате — свежесть 4 раза в год без картинок.
- [темы] «True dark» для OLED: фон #000, glow и тени выключены — батарея и ночной вариант.
- [темы] Авто-вечер: тёмная тема принудительно после 22:00 (настройка).
- [акцент] Персональный акцент: 6–8 палитр с заранее проверенными AA-парами, переключение через data-accent — «моё» приложение.
- [акцент] Акцент «по настроению недели»: --accent мягко сдвигается по среднему настроению за 7 дней.
- [ритуалы] Время суток в токенах: утро теплее, ночь — минимум свечения; класс на body по часу.
- [ритуалы] Линия-прогресс дня под шапкой: градиентная полоса по доле выполненных дел.
- [ритуалы] «День закрыт»: при 100 % кольца hero получает спокойный тёмный вариант и короткий glow.
- [ритуалы] Ритм недели: воскресенье вечером тёплый glow, понедельник утром — холодный «свежий».
- [ритуалы] Пульс «сегодня» в календарях (breathing-outline, при разрешённом движении).
- [ритуалы] Праздник в интерфейсе: чип дня рождения с мягким glow.
- [микро] Кольцевая вспышка вокруг .check при отметке (одна итерация).
- [микро] «Откладывание» выполненного: .item.done через 400 мс приглушается и опускается на 1–2 px.
- [микро] Новая строка списка появляется с fade+slide; удаляемая растворяется.
- [микро] Плавающий индикатор .seg: подложка движется transform между сегментами.
- [микро] Анимация прогресс-баров через transition на --w.
- [микро] Тост с цветной левой кромкой по типу (ok/error).
- [микро] Единый «отклик нажатия» scale .96 чипам, табам и карточкам (сейчас только кнопкам).
- [микро] Точка в .sync-badge пульсирует во время синхронизации.
- [микро] Hover-подъём translateY(-1px)+тень только под pointer:fine и только у интерактивных карточек.
- [иерархия] Тень = интерактивность: статичные карточки плоские, нажимаемые — с тенью.
- [иерархия] Карточка «главное дело дня» в hero-тинте с текстом на ступень крупнее.
- [иерархия] Число-герой экрана (остаток бюджета, серия) — --t40 с градиентным текстом.
- [иерархия] Просроченное: полоса-пульс слева и метка «на N дн» — срочность по форме, не по цвету.
- [иерархия] Счётчики в заголовках разделов: чип «(3)» справа от «Дела».
- [иерархия] «Факт» и «вывод» различаются: инсайты-рекомендации с градиентной кромкой сверху.
- [типографика] Small-caps для .meta через font-variant-caps вместо uppercase.
- [типографика] Приветствие с clamp()-размером по длине имени.
- [типографика] text-wrap:balance на текстах дел и заголовках карточек.
- [плотность] Настройка плотности (компактно/обычно/просторно): data-density масштабирует --s2…--s6.
- [плотность] Визуальный слой для simple-режима: скрыты meta-строки, цели касания 48 px.
- [пустые состояния] Два тона пустоты: «всё сделано» (тёплый) против «ещё не начато» (нейтральный).
- [пустые состояния] Микро-совет дня под кнопкой пустого состояния (ротация по дате).
- [иконки] Двухтональность: второй path части иконок с opacity .4.
- [иконки] Точка-бейдж 6 px на табе нижней панели для непрочитанного вместо цифр.

## 3. Функционал

**Новые типы и разделы (в рамках событийной модели)**
- [Дом] Питомец: имя, вес, прививки, ветеринар — сроки прививок приходят сами.
- [Дом] Растения: вещи с правилом ухода «каждые N дней» и отметкой «полил».
- [Дом] Документы со сроком действия (validUntil): напоминание за 90 и 30 дней.
- [Дом] Обслуживание техники: интервал ТО от последнего itemlog repair.
- [Дом] Кладовая со сроками: «съесть до», пришло/ушло.
- [Досуг] Журнал чтения: страниц всего/прочитано, темп, прогноз окончания, итог «книг за год».
- [Здоровье] Пользовательские замеры: свой kind для measure (название, единицы, цель) без правок кода.
- [Люди] Журнал контактов: дата, канал, «о чём говорили» — честное «давно не писал» и тема прошлого разговора.
- [Люди] Важные даты человека кроме дня рождения (годовщина, даты детей).
- [Рефлексия] Капсула времени: письмо себе с датой вскрытия.

**Связки между разделами**
- [Деньги×Зарплата] Цена в часах работы: подпись «это 6 ч работы» в wish и expense — трезвит перед тратой.
- [Деньги×Привычки] Привычка отказа с ценой: «не купил кофе — 250 ₽», за месяц «сэкономлено» и кнопка «в копилку».
- [Деньги×Привычки] День без трат: автоопределение по журналу, серия и «лучшая неделя».
- [Деньги×Задачи] Список покупок → расход: отметил купленным — готовый черновик expense.
- [Деньги×Дом] Продал вещь → доход: при статусе «продано» предложение записать income.
- [Дом×Деньги] Цена одного надевания: priceMinor ÷ число wear — рейтинг «выгодных» и «мёртвых» вещей.
- [График×Сон] Сон по типам смен: «после ночной ты спишь на 1,2 ч меньше».
- [График×План] planday читает график: в смену план короче, после ночной — восстановление.
- [Привычки×График] Привычки по типу дня графика: «только в выходные по графику», в рабочие — минимальная версия.
- [OKR×Журнал] Результаты, которые считаются сами: KR как запрос к журналу (count(workout), sum(goalmove)) — цели оживают без ручного ввода.
- [Люди×Деньги] Долги в карточке человека (связать debt.who с person).
- [Лекарства] Курс с концом: дата окончания, «осталось 5 дней», отметка «курс завершён».
- [Деньги×Подписки] Аудит подписок по факту: раз в месяц вопрос «пользовался?» → кандидат на отмену.
- [Зарплата×Деньги] Зарплатный ритуал: в день salaryDay чек-лист распределения дохода.

**Правила и шаблоны**
- [Правила] Цепочки задач: после выполнения создаётся следующая из шаблона.
- [Правила] Сезонные чек-листы по дате («подготовка к зиме», «перед отпуском»).
- [Правила] Умный ввод шире: «принял таблетку» → medlog, «надел пальто» → itemlog, «общался с мамой» → контакт.
- [Правила] Округление трат до 50/100 ₽, разница копится виртуально; раз в неделю «перевести 147 ₽ в копилку».
- [Правила] Защита выходного: больше трёх задач в выходной по графику — мягкое предупреждение.
- [Сегодня] Обратные отсчёты: «до отпуска 12 дней», «до конца квартала 41 день, прогресс OKR 55 %».
- [Рефлексия] Колесо баланса с проверкой фактом: самооценка областей рядом с реальными цифрами.

**Импорт/экспорт и семья**
- [Импорт] Мастер переезда: задачи и заметки из CSV/Markdown (Keep, Todoist) с предпросмотром и защитой от дублей.
- [Импорт] Импорт .ics: события календаря → задачи и даты людей, выборочно.
- [Экспорт] График смен в .ics с учётом праздников — семья видит, когда ты на смене.
- [Семья] Семейный экран: второе устройство в режиме «только общие списки» (покупки, дела по дому); дневник и деньги скрыты.
- [Семья] Делегированное дело: «попросил жену купить…» — кому, что, когда спросить о результате.
- [Семья×Дом] Чек-листы сборов из инвентаря: «в поездку», «на смену» — отметки «собрано» и «вернуть на место».

**ТОП-5:** 1) OKR-результаты, считающиеся сами; 2) цена в часах работы; 3) planday читает график смен; 4) список покупок → расход; 5) журнал контактов.

## 4. Хакерские штучки

**Глубокие ссылки и быстрый вход**
- [URL] Схема kompas://add?text=… и ?q=… — ссылка открывает умный ввод с готовым черновиком; «кнопки-сценарии» ярлыками на рабочем столе.
- [URL] Стабильные адреса записей #/note/<id>, #/task/<id> — заметки ссылаются друг на друга.
- [Шаринг] Шаринг сразу в capture: присланная фраза «такси 450» → черновик расхода одним тапом.
- [Действия] Ответ прямо в уведомлении: «Как день? 1–5» — отметка настроения без открытия приложения.
- [Действия] Тряска телефона (devicemotion, только APK) как настраиваемый жест-якорь.
- [PWA] Screen Wake Lock в тренировках и фокус-таймере.

**Локальный query-режим**
- [Query] Консоль запросов к журналу: type:expense amount>1000 last:30d — результат таблицей и кнопкой «в CSV».
- [Query] Сохранённые запросы как «виды»: «все понедельники со сном < 6 ч» — вторая вкладка поиска.
- [Query] Поиск по регулярному выражению с предпросмотром и безопасной массовой операцией (diff + отмена).
- [Query] Хроно-запросы: все записи за произвольный набор дат одним пакетом в Markdown — отчёт о периоде.
- [Query] Cron-запросы: сохранённый запрос, чей результат сам становится событием («каждое воскресенье итог недели в заметку»).
- [Query] explain(id): почему я вижу эту запись — цепочка правок и слияний.

**Автоматизации по правилам**
- [Авто] Триггеры на шине событий с «сухим прогоном»: правило сначала показывает, сколько раз сработало бы за прошлый месяц.
- [Авто] Цепочки с задержкой: «задача просрочена 3-й раз → предложить разбить», «привычке 20 дней → предложить усложнить».
- [Авто] Авточерновик итога дня в 23:30 с уже подсчитанными фактами.
- [Авто] Watchdog на самого себя: три дня без событий → задача «проверь, всё ли живо».

**PWA / сервис-воркер**
- [SW] Сторож целостности: SW сверяет хэши файлов оболочки; при повреждении — аварийная rescue-страница с кнопкой «Экспорт данных».
- [SW] BroadcastChannel-мост: второе окно как «дисплей» (таймер на планшете, ввод на телефоне).
- [SW] Автопилот копий через File System Access: ротация из 7 зашифрованных копий в выбранной папке с проверкой чтения.
- [SW] Periodic Background Sync: тихая синхронизация и сверка ночью на зарядке.

**QR, NFC, обмен без сервера**
- [QR] WebRTC-сигналинг через QR: перенос зашифрованного архива P2P на новый телефон без сети.
- [QR] Анимированные QR-пачки: большой бэкап серией кодов с экрана — работает в самолёте.
- [QR] Печатные QR-закладки на физические места: код на аптечке открывает её состав.
- [QR] QR-пакет для близкого: список шифруется одноразовым ключом прямо в QR.
- [NFC] NFC-метки как физические кнопки: бейдж у двери — «вышел на пробежку».
- [QR] QR-спаривание нового устройства: одноразовый токен на 5 минут, вход без ввода пароля.

**Продвинутые выгрузки**
- [Экспорт] Самодостаточный HTML-архив: один файл с данными и встроенным мини-движком — читается через 20 лет без приложения.
- [Экспорт] SQLite-снимок через sql.js (WASM) — настоящая база для произвольного SQL.
- [Экспорт] Git-friendly выгрузка: дневник папкой YYYY/MM/DD.md с Obsidian-совместимыми [[ссылками]].

**Гики-режим, копии, восстановление**
- [Гики] Панель инженера: размер БД по типам, латентность sync, «отладочный бандл» одной кнопкой.
- [Гики] Replay-проигрыватель: перемотка состояния на любую дату (event sourcing даром).
- [Бэкап] Слепой снапшот на своём сервере: раз в неделю зашифрованный блоб отдельным endpoint'ом — потеря всех устройств перестаёт быть катастрофой.
- [Бэкап] Бумажная копия: экстренные данные и код восстановления листом с QR-блоками.
- [Бэкап] Стего-копия: зашифрованный архив в обычном PNG (младшие биты) — копия «фото котика» в галерее.
- [Восстановление] «Ctrl+Z по жизни»: окно отмены на час со списком изменений человеческими словами.
- [Восстановление] Diff двух копий: открыть старый бэкап рядом с текущими данными, забрать точечно.
- [Восстановление] Хирургия записей: гик-редактор сырого события с обязательным событием-исправлением.
- [Синхронизация] LAN-режим: домашний server/node как семейный хаб по Wi-Fi без облака; «чемоданчик» перед поездкой.

**ТОП-5:** 1) самодостаточный HTML-архив; 2) WebRTC-перенос через QR; 3) консоль запросов + сохранённые виды; 4) триггеры с «сухим прогоном»; 5) слепой снапшот на своём сервере.

## 5. Просто полезности

- [кнопка пользы] «Самое полезное прямо сейчас»: одна большая контекстная кнопка на «Сегодня» (утром — бриф, днём — «есть 10 минут», вечером — итог дня).
- [кнопка пользы] Прозрачное правило выбора кнопки: просрочка → отметка утра → главное дело → минимум привычки → итог дня.
- [тёплые мелочи] Экран «Всё сделано»: случайная запись из копилки радостей или тёплая строка вместо пустой подписи.
- [тёплые мелочи] Тёплый микро-итог вечером одной человеческой фразой рядом с сухим summaryText.
- [тёплые мелочи] «Неделя в трёх словах»: подпись уходящей недели, лента года.
- [тёплые мелочи] Тёплая вырезка месяца: 5 лучших моментов одним текстом для копирования/печати.
- [тёплые мелочи] Годовщина в приложении: «Ты ведёшь Компас уже N дней…».
- [тёплые мелочи] Редкая открытка «первый раз за долгое время» — тихий тост, не система достижений.
- [забота] Важные даты близких кроме дня рождения: «Завтра важный день у …» с кнопкой «написать».
- [забота] «Проверь себя» раз в две недели: три мягкие отметки без цифр (тело, голова, дела).
- [забота] Мягкое возвращение после болезни: первый день в режиме «тяжёлый день».
- [забота] Болезнь дольше 3 дней → при завершении предложить задачу «записаться к врачу».
- [забота] План на плохой день, написанный заранее самим собой — показывается рядом с подсказкой о долго низком настроении.

- [анти-перегрузка] «День тишины»: запланированный день без счётчиков, дельт, серий и предложений — только дела и минимум.
- [анти-перегрузка] Неделя «ничего нового»: приложение не предлагает новые курсы, эксперименты и функции 7 дней.
- [анти-перегрузка] Мягкий счётчик входящих: после третьей новой задачи за день — «может, что-то подождёт до завтра?».
- [анти-перегрузка] Кнопка «пережить день»: переносит все необязательные дела на завтра одним нажатием, с отменой.
- [анти-перегрузка] Быстрый чип «на выходные» у задачи рядом с «завтра» и «через неделю».
- [быт] Список в аптеку: у лекарства кнопка «заканчивается», список копируется текстом.
- [быт] Чек-лист «лекарства в дорогу» из активного списка с учётом приёмов утро/день/вечер.

## Сводный шорт-лист директора (10 кандидатов на ближайшие этапы)

Критерий: польза владельцу на каждый день ÷ объём работ ÷ риск сломать данные.

1. **Одна кнопка пользы на «Сегодня»** (полезности ТОП-1) — логика данных уже есть в daycards.js.
2. **Список в аптеку из лекарств** (полезности ТОП-2) — одно поле и кнопка в meds.js.
3. **Спиральная проверка в курсах** (курсы ТОП-2) — почти бесплатно в pickCheckItems, сильный эффект удержания.
4. **Ошибки по видам заданий в zcheck** (курсы ТОП-1) — маленькое расширение payload, основа адаптивности.
5. **Цена в часах работы** (функционал ТОП-2) — одна подпись, данные уже есть (paycfg).
6. **OKR-результаты, считающиеся сами** (функционал ТОП-1) — «вау» в рамках архитектуры.
7. **Персональный акцент через data-accent** (дизайн ТОП-1) — чисто токенная персонализация с AA-проверкой.
8. **День тишины / неделя «ничего нового»** (полезности ТОП-3) — один общий флаг-фильтр подсказок.
9. **Самодостаточный HTML-архив** (хакерские ТОП-1) — «вечная» читаемость данных без приложения.
10. **Слепой снапшот на своём сервере** (хакерские ТОП-5) — закрывает потерю всех устройств разом.

Отдельно отмечены пересечения агентов (усиливает приоритет): документы со сроком действия и гарантии на «Сегодня» (функционал + полезности), журнал контактов и важные даты близких (функционал + полезности), важность «бережного» тона во всех пяти списках.
