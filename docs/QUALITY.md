# Нефункциональные требования с числами

Цель — чтобы «быстро», «надёжно» и «безопасно» можно было проверить, а не только пожелать. «Проверка» показывает, чем это подтверждается.

| Область | Требование | Проверка |
|---|---|---|
| Запуск | Интерфейс виден за ≤ 2 с на телефоне; в автотестах допуск ≤ 5 с (медленный сервер) | В «О приложении» строка «Запуск: …»; `tests/e2e-r36.mjs` |
| Отклик | Нажатие даёт реакцию ≤ 100 мс; тяжёлые экраны считаются только когда открыты | Ручная проверка на телефоне, `CHECKLIST.md` |
| Размер | Весь веб-код ≤ 1,4 МБ, один файл ≤ 64 КБ | `tests/size.test.mjs` |
| Данные | До 200 000 записей в одном файле копии; резервная копия проверяется на чтение до сохранения | `parseImport`, `tests/domain.test.mjs` |
| Совместимость данных | Записи всех прошлых версий читаются; копия более новой версии отклоняется | `tests/compat.test.mjs`, `tests/registry.test.mjs` |
| Безопасность | AES-256-GCM, PBKDF2-SHA256 600 000 итераций; на диске нет открытого текста при включённом пароле; после 5 неверных попыток пауза растёт | `tests/crypto.test.mjs`, `tests/e2e-security.mjs` |
| Приватность | Нет сетевых вызовов, кроме сервера синхронизации; личные тексты не попадают в выгрузку для аналитики | `tests/static.test.mjs`, `docs/EVENTS.md` |
| Доступность | Кнопки не меньше 44 px по высоте; размер текста 100/115/130 %; светлая и тёмная темы | `style.css`, ручная проверка |
| Надёжность выпуска | Сайт обновляется только после зелёных модульных и браузерных проверок; откат одним коммитом | `.github/workflows/pages.yml`, `docs/RELEASE.md` |
| Качество кода | Нет циклов между модулями; логика не зависит от интерфейса | `tests/deps.test.mjs` |
| Офлайн | Всё, кроме синхронизации, работает без интернета | офлайн-кэш `sw.js`, `tests/static.test.mjs` |

Числа в таблице — рабочие цели. Если цель меняется, правь таблицу и тест вместе.
