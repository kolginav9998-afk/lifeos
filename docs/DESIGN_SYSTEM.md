# Дизайн-система

Стиль: «спокойный интеллектуальный инструмент». Глубокий графит вместо чёрного, один главный фирменный акцент (фиолетово-синий градиент) и приглушённые смысловые цвета, тени только для слоёв, минимум шума. Все значения живут в токенах `style.css`; цвета в правилах не пишем. Блок оформления второго раунда лежит в конце `style.css` под заголовком `/* ===== design2 ===== */`.

## Токены

Цвет (верх `style.css`, светлая и тёмная темы; контраст пар проверяет `tests/r313.test.mjs`):
`--bg`, `--card`, `--soft`, `--line`, `--text`, `--muted`, `--accent`, `--accent2`, `--ok`, `--danger`, `--warn`, `--grad` (только для главных кнопок и кольца), `--grad-soft`, `--glass`, `--glow1`, `--glow2`, `--shadow`, `--shadow-lg`, `--r`.
Тёмная тема: фон `#13151c` (графит), карточки и «мягкие» поверхности — полупрозрачный белый 4,5 % и 6,5 %. Свечение фона слабое, тени без цвета.

Производные (блок design2, работают в обеих темах):
- Оттенки состояний: `--tint-accent`, `--tint-ok`, `--tint-danger`, `--tint-warn` (цвет состояния 13–15 % поверх поверхности).
- Слои: `--hi` (приподнятая поверхность, например выбранный сегмент), `--shadow-sm` (строки списков), `--toast-bg`, `--toast-fg`, `--toast-act`.
- Графики: `--c1`…`--c5` (категории), `--m1`…`--m5` (шкала настроения от плохого к хорошему).
- Движение: `--ease`.

Шкалы (используем только их):
- Текст: `--t12 .75rem`, `--t14 .875rem`, `--t16 1rem`, `--t20 1.25rem`, `--t24 1.5rem`, `--t32 2rem`, `--t40 2.5rem`. Межстрочный интервал: текст 1,5, заголовки 1,2. Числа — `font-variant-numeric: tabular-nums`.
- Отступы: `--s1 4`, `--s2 8`, `--s3 12`, `--s4 16`, `--s5 24`, `--s6 32`, `--s7 48`, `--s8 64` px. Промежуток между блоками экрана — `--s4`, между строками списка — `--s2`.
- Радиусы: `--r4` (точки, ячейки), `--r8` (чипы, значки, подписи), `--r12` (кнопки, поля, строки списков, всплывающие сообщения), `--r16` (карточки, нижняя панель, «герой», окна). Круг только у аватара, кольца, отметки задачи и переключателя.

## Режимы

Маршрутизатор (`go()` в `app.js`) ставит `data-mode` на `#app`; в `style.css` режим задаёт `--mode-accent` (по умолчанию равен `--accent`):

| режим | экраны | акцент |
|---|---|---|
| `memory` (по умолчанию) | Сегодня, Привычки, Люди, Дневник, Здоровье, Тренировки, Заметки | основной (фиолетовый) |
| `learn` | Учёба, Навыки, Тесты, С нуля, Дикция | `--md-learn` (синий) |
| `finance` | Деньги | `--md-fin` (бирюзовый) |
| `analytics` | Аналитика, Цели, Планы, Рефлексия | `--md-ana` (голубой) |
| `security` | Настройки, Профиль, экраны входа и пароля | `--md-sec` (серо-синий) |

`--mode-accent` используют: линия под заголовком, выбранный пункт второй строки, индикатор нижней панели, столбцы и линии графиков, полосы прогресса, иллюстрации пустых экранов, подсказки-блоки. Главные кнопки и кольцо дел остаются фирменными (градиент). Новый экран добавляем в `MODE_OF` в `app.js`.

## Компоненты (общие классы, а не правки под экран)

- Карточка `.card` (+ `.calm`, `.tight`; сворачиваемая — `details.card`); настройки `.settings-card`; блоки-выводы `.insight`, `.okr`; «герой» `.hero`.
- Строки списков `.item`, `.entry`, `.track-card`: отметка `.check` (значок «галочка»), текст `.text`, подпись `.meta`, удаление `.del` (значок «крестик»).
- Чипы `.chip` (кнопка-действие со значком) и `.chip.static` (показатель с точкой цвета режима, `.danger` — просрочено); полоса чипов `#summary` прокручивается по горизонтали.
- Кнопки: `button` (вторичная, заливка `--soft`), `.primary` (градиент), `.danger` (тонировка), `.link` (текстовая), `.icon-btn`.
- Переключатель `.seg-group > .seg`; вторая строка разделов `.subnav`; нижняя панель `#tabs`.
- Поля: `input`, `select` (стрелка рисуется градиентами), `textarea`; подпись `.field > span` или `.rating-label`; подсказка `.hint`; ошибка `.error` (тонированный блок, пустая не занимает места); `:user-invalid` подсвечивается. Флажок `input[type=checkbox]` — свой вид (скруглённый квадрат с галочкой). Вид «переключатель» для настроек пробовали и убрали: с ним `page.check()` в `tests/e2e-security.mjs` обнулял поля пароля.
- Пустое состояние: `emptyState({ art, title, text, action, id })` из `ui.js` → `.empty`, `.ill`, `.empty-t`, `.empty-p`, `.empty-a`. Иллюстрация собирается из DOM (`illustration(name)`), цвета через классы `.ill-*`. Заголовок можно менять: `box.msg.textContent`.
- Сообщение `toast(text, { actionLabel, onAction, ms, kind })`: значок (`kind: 'error'` определяется и по началу текста), кнопка действия, полоска оставшегося времени `.toast-bar`. В `#toast` одна кнопка — действие.
- Окна на весь экран `.overlay` (повторение карточек, проверки): `.sess-top`, `.flash`, `.grade` (`again`/`hard`/`good`), `.bt-box`, `.kp`.
- Графики: `sparkline()` (область с градиентом и конечная точка с ореолом: `.spark-area`, `.spark-g0/.spark-g1`, `.spark-halo`, `.spark-dot`), столбцы `.bars/.bar-col/.bar-fill/.bar-n/.bar-d` (значение над столбцом, `.current` выделяет период), полосы `.progress`, категории `.cat` (цвет `--k` из `--c1…--c5`), настроение `.mood-dot.m1…m5`, тепловая карта `.mh-1…5`, кольцо `ring()`.
- Привычка: `.h-top` (кольцо регулярности за 30 дней, название, серия `.streak`, `.hot` от 3 дней), действия `.h-actions`.
- Значки `icon(name, size, cls)` из `ui.js` (класс `ic ic-<имя>`): tasks, habits, money, notes, more/settings, search, lock, eye, eyeOff, diary, tests/pulse, growth, plus, minus, check, checkCircle, x, chevR, chevL, chevD, edit, trash, calendar, bell, heart, book, target, flame, clock, share, download, upload, user, users, star, alert, info, volume, cloud, sync, gift, zap, play, undo, copy, flag, shield, moon, list, dumbbell. Обводка 2, закруглённые концы, цвет `currentColor`.
- Вход и пароль `.lock`, `.gate`: свечение, карточка стекла, мягкое парение значка (только без `prefers-reduced-motion`).

## Доступность

- Контраст: пары основных токенов проверяет `tests/r313.test.mjs` (WCAG AA, 4,5:1). Акценты режимов (`--md-*`) проверены вручную: не ниже 4,5:1 на карточке в обеих темах. Белый текст на градиенте кнопок — тоже не ниже 4,5:1.
- Движение: все анимации (появление экранов, сообщение, окно, галочка, парение значка, пламя серии) только внутри `@media (prefers-reduced-motion: no-preference)`; общее правило `reduce` в конце старого блока гасит остальное. Анимируем только `transform` и `opacity`.
- Производительность: размытие фона (`backdrop-filter`) только у шапки и нижней панели; у длинных списков лёгкая тень `--shadow-sm` без размытия.
- Значки `aria-hidden`; смысл несёт текст или `aria-label` кнопки. Цель касания не меньше 36 px (основные кнопки 44 px). Состояние не передаётся одним цветом: у ошибки есть текст, у выполненного дела — галочка.
- Тесты закрепляют несколько символов в тексте, их не заменяем значками: `🎂` в чипе дня рождения, `✕` в строке «заряда» (`.chg-row`), `✓` в кнопках привычки (`.h-min`, `.h-full`) и в номере урока, `✓` в сводке отметки дня.
