# Документы: что где лежит

Короткий указатель: у каждого документа одна строка о том, зачем он нужен. Главная страница проекта: [../README.md](../README.md). Справка для человека есть и в самом приложении: «Ещё» → «Справка» (тексты в [../help.js](../help.js)).

## Для владельца
- [GUIDE.md](GUIDE.md): инструкция простыми словами: что где, как поставить и обновить, резервные копии, что нового в каждой версии.
- [CHECKLIST.md](CHECKLIST.md): что проверить на телефоне после обновления, шаг за шагом.
- [SERVER.md](SERVER.md): сервер синхронизации: как устроен, что он видит, как его развернуть и что делать, если что-то пошло не так.

## Для тех, кто меняет приложение
- [RELEASE.md](RELEASE.md): как выпустить версию, проверить её и откатить.
- [QUALITY.md](QUALITY.md): требования с числами (скорость, размер, безопасность) и чем каждое проверяется.
- [ADR.md](ADR.md): принятые решения по устройству приложения и почему они такие.
- [GLOSSARY.md](GLOSSARY.md): словарь: одно слово означает одно и то же везде.
- [AI-TASK.md](AI-TASK.md): шаблон постановки задачи ИИ-помощнику.

## Данные
- [EVENTS.md](EVENTS.md): все типы записей (файл создаётся из `registry.js`, руками не правится).
- [ER.md](ER.md): связи между данными: диаграмма (создаётся из `registry.js`).
- [STATES.md](STATES.md): диаграммы состояний основных записей.
- [analysis/README.md](analysis/README.md): разбор выгрузки на компьютере: скрипт и ноутбук Python.

## Идеи и планы
- [IDEAS.md](IDEAS.md): «полка» идей и план этапов.
- [COUNCIL.md](COUNCIL.md): «совет из 50»: 750 предложений, склад идей на будущее.
