# Life OS

Личные задачи. PWA: работает офлайн, данные только на телефоне (IndexedDB).
Без сборки и зависимостей: чистые HTML/JS.

## Проверка на телефоне (критерий R0)
1. Открыть ссылку в браузере телефона → «Добавить на главный экран».
2. Включить авиарежим, добавить 5 задач, отметить одну, закрыть и открыть приложение снова.
3. Данные на месте → R0 пройден.

## Локально
```bash
python3 -m http.server 8080   # http://localhost:8080
node --test tests/events.test.mjs          # юнит-тесты
node tests/e2e.mjs                         # браузер, офлайн, экспорт/импорт (нужен playwright)
```

## Возможности
Задачи (сроки, повторы, разбор дат в тексте), привычки, расходы и доходы, заметки, дневник и здоровье,
поиск, итоги недели, защита паролем с шифрованием данных, зашифрованные резервные копии, экспорт (JSON, CSV, Markdown).
Развитие: 8 обучающих курсов с интервальными повторениями, ежедневные проверки (11 тестов), аналитика личных закономерностей, личные эксперименты, выгрузка ZIP/CSV и отчёты.
Жизнь: умный ввод фразами, тренировки, фокус-таймер, лекарства, планы (лимиты, копилки, подписки), заметки с тегами и ссылками, календарь .ics.
Аккаунт одного пользователя и синхронизация между устройствами (сервер: [docs/SERVER.md](docs/SERVER.md)), шифрование на устройстве.
Один код для сайта и Android-приложения.

## Тесты
```bash
npm test               # юнит-тесты и статические проверки (190+)
npm run test:e2e       # браузерные сценарии: задачи, модули, безопасность, синхронизация, здоровье, учёба, проверки (нужен playwright)
npm run icons          # пересоздать иконки из assets/icon-source.webp
```

## Модель данных
Всё — события: `{id, type, ts, payload, source, confidence, evidence}`.
Задача = событие `type: "task"`. Новые модули (расходы, заметки, навыки) добавляются
новыми типами событий, без новых таблиц.
