# Компас

Личное приложение для дел, привычек, дневника, здоровья, денег и учёбы. Работает на телефоне Android (приложение) и в браузере (сайт), без интернета тоже. Записи лежат на самом устройстве, а копия, в зашифрованном виде, на твоём собственном сервере: поэтому они есть на всех твоих устройствах. В адресах и именах файлов название осталось прежним: `lifeos`.

## Установить и обновить за 5 строк
1. **Android:** открой на телефоне ссылку https://github.com/kolginav9998-afk/lifeos/releases/download/latest-apk/lifeos.apk , скачай файл и нажми на него. Если телефон спросит, разреши установку.
2. **Без установки:** сайт https://kolginav9998-afk.github.io/lifeos/ , в браузере телефона выбери «Добавить на главный экран».
3. **Первый вход:** логин и пароль. Когда создаёшь аккаунт, ещё нужен код установки сервера; потом приложение один раз покажет код восстановления: запиши его на бумагу.
4. **Обновить:** «Ещё» → «Профиль» → «Версия и обновления» → «Проверить обновления» → «Обновить». Данные остаются на месте.
5. **Не вышло?** Скачай файл по ссылке из первой строки и установи поверх старого приложения.

## Где справка
В самом приложении: «Ещё» → «Справка». Там ответы простыми словами: как обновить приложение, что делать, если забыл пароль или потерял телефон, как перенести всё на новый телефон, где архив и код восстановления. Можно искать по словам. При самом первом входе приложение коротко покажет три главных места: профиль, архив и обновления.

Подробная инструкция для владельца: [docs/GUIDE.md](docs/GUIDE.md). Все документы одним списком: [docs/README.md](docs/README.md).

## Что умеет
Задачи (сроки, повторы, разбор дат в тексте), привычки, расходы и доходы, заметки, дневник и здоровье, поиск, итоги недели, цели и навыки.
Развитие: обучающие курсы с интервальными повторениями, ежедневные проверки, аналитика личных закономерностей, личные эксперименты, выгрузка и отчёты.
Жизнь: умный ввод фразами, тренировки, фокус-таймер, лекарства, планы (лимиты, копилки, подписки), календарь .ics.
Безопасность: пароль и шифрование на устройстве, аккаунт одного человека с синхронизацией между устройствами (сервер: [docs/SERVER.md](docs/SERVER.md)), архив всех данных одним файлом.
Один код для сайта и Android-приложения.

## Для разработчиков
```bash
python3 -m http.server 8080                # сайт локально: http://localhost:8080
npm test                                   # модульные проверки и статические правила (сотни проверок, около 10 секунд)
node tests/e2e-smoke.mjs                   # один сценарий в браузере (нужен playwright); все сценарии: npm run test:e2e
npm run icons                              # пересоздать иконки из assets/icon-source.webp
```
Выпуск и откат: [docs/RELEASE.md](docs/RELEASE.md). Решения по архитектуре: [docs/ADR.md](docs/ADR.md). Тексты справки лежат в `help.js` (только данные): новую статью добавляют записью в список.

## Модель данных
Всё — события: `{id, type, ts, payload, source, confidence, evidence}`. Задача = событие `type: "task"`. Новые модули добавляются новыми типами событий, без новых таблиц. Список типов: [docs/EVENTS.md](docs/EVENTS.md).
